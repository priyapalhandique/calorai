# Acknowledgements

## FortyGuard-Tech / temperature-api-quickstart

`calorai` is built on top of the official
[FortyGuard-Tech/temperature-api-quickstart](https://github.com/FortyGuard-Tech/temperature-api-quickstart)
template, which we were instructed to use as the starting point for
[FortyGuard Hackathon'26](https://www.fortyguard.com/hackathon26)
("Building the World's Temperature AI").

The following are Copyright © FortyGuard and were provided as part of the
official template:

- `fortyguard/` — the Python client for the FortyGuard tOS Enterprise API
  (submit-and-poll handling, all endpoint wrappers, sample AOIs/points)
- `notebooks/` — endpoint walkthroughs and narrative use-case workflows
- `docs/images/` — README figures
- `.env.example`, `requirements.txt`, `LICENSE`

`calorai/` (the physics engine, agent orchestrator, tool registry, and web app)
is original work by the calorai team, layered on top of this template.
